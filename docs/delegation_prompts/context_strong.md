Before calling the delegate, read SOURCE_CHANGES.diff once and write `.delegation/context.json`: a JSON object with one entry per failing test FILE (key = the file name, for example "CartTest.java") of the form {"source_changes": "<the parts of the diff the delegate needs for this file, copied, at most about 1500 characters>", "hint": "<one sentence on what changed>"}. Then call the delegate with `--context strong` (it then uses your selection instead of its automatic one).
