Method (one-call repair): run `tools/repair` ONCE. It does everything without you: applies the pure renames, runs the tests, calls the delegate (up to 3 rounds) while tests fail, runs the tests again and the review, and prints ACCEPT or ESCALATE. If it prints "REPAIR STILL RUNNING", call `tools/repair --wait` and nothing else (no polling, no sleeping). Do not read SOURCE_CHANGES.diff or test files before it has finished.
