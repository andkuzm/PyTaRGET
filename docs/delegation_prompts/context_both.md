Before calling the delegate, read SOURCE_CHANGES.diff once and write `.delegation/context.json`: a JSON object with one entry per failing test FILE (key = the file name, for example "CartTest.java") of the form {"source_changes": "<anything the automatic selection is likely to miss, copied from the diff, at most about 800 characters>", "hint": "<one sentence on what changed>"}. Then call the delegate with `--context both` (it adds your entries to its automatic selection).
