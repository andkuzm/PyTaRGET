Method (automated start): run `tools/start` ONCE first. It needs no thinking from you: it applies every pure rename found in SOURCE_CHANGES.diff to the tests (do not redo or check these renames) and prints the test result that is left. Do not read SOURCE_CHANGES.diff or test files before the delegate has run.
Then call `tools/delegate` (it repairs every failing test file). If it prints "DELEGATE STILL RUNNING", call `tools/delegate --wait` and nothing else (no polling, no sleeping). Run the tests again; if tests still fail, call `tools/delegate` again, at most 2 more times. Finally verify (see below) and repair whatever is still wrong yourself.
