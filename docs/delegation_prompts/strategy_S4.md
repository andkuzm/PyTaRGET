Method (routing): first run `tools/run_tests` and read SOURCE_CHANGES.diff. Sort the failing test files into two groups.
(a) PLAIN REPLACE: the test only needs a mechanical rewrite that is the same everywhere (a renamed method, class, enum constant or package; changed imports). Do these yourself with one targeted search-and-replace per rename (for example `sed -i` over the test directory); do NOT read these files or write them out by hand.
(b) LOGIC CHANGE: the behaviour changed, so expected values, expected exceptions or the test logic itself must be rethought. Delegate these with `tools/delegate --units <file names or Class#method, comma separated>` AFTER the plain replacements are done (so that the delegate sees a smaller problem), then run the tests, and call the delegate again for what still fails (at most 2 more calls). A file can contain both kinds: do its plain replaces first, then delegate the rest of that file.
Finally verify (see below) and repair yourself whatever the delegate left wrong.
Note: `tools/delegate` can take up to 4 minutes; call it with a Bash timeout of 300000 ms and wait for it in that single call (do not poll, sleep or run other tests meanwhile).
