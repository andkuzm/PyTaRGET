Method (one-call preparation): run `tools/repair` ONCE first. It does the mechanical work without you: applies the pure renames, updates a message change that repeats across several failing tests, runs the tests and, when they all pass, the review, and prints ACCEPT or ESCALATE. No model is involved in it. Whatever still fails after it is yours to repair. If it prints "REPAIR STILL RUNNING", call `tools/repair --wait` and nothing else. Do not read SOURCE_CHANGES.diff or test files before it has finished.
