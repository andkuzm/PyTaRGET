Agent vs no agent: summary of the checked plausible@1 scores (weighted with the population sizes of the contrast subsets) - updated 2026-11-19 (Java B/BC added)
"No agent" = prompt-only (one call, fixed prompt: test context, BROKEN LINES marked, up to 4 source hunks; B adds the failure output of the broken test, C the definitions of the changed
symbols). "Agent" = mini-SWE-agent + Qwen3-Coder-30B-A3B in an offline sandbox with a shell in the repository (read/grep/run tests), NO marked broken lines, sibling-safe workspaces on
Python, 40 or 80 calls. Each column uses the cases judged in every column of its table; samples are small (about 60 cases, +-7 points per group), runs sampled at temperature 0.7.

COST: a prompt-only run is one model call (plus ~160 / ~300 tokens of context for B / BC); the agent used a median of 29 (Java) / 43 (Python) calls and 64 / 79 s per case at the 80-call limit (22 / 33 calls at 40).

READING
- The agent lifts the same small model by about 30 points on Python (about 13 over the prompt that already holds the failure output) and, on Java, by 19 (strict) to 26 (relaxed) points over Qwen3-Coder with the best prompt (BC, 44.0%); paired relaxed +20/-5.
- Against the strongest prompt-only setup the picture is mixed: on Java particle-1 with B+C context (74.5%) is slightly above the 80-call Qwen agent (relaxed 70.3%, paired +8/-11; strict 63.4%, +6/-13); on Python particle-1 with the failure output (57-58%) is above the agent (48.3%).
- The failure output is worth +20 to +27 points on Python but only +6 to +10 on Java; the definitions add nothing or hurt slightly in both languages.
- The step limit mattered on Java (47.4 -> 63.4 strict) but not on Python (46.1 -> 48.0).
CAVEATS: the Python first agent run (65.2%) was inflated by already-repaired sibling tests in the workspace, all agent numbers above use sibling-safe workspaces; on Java the other tests of the commit stay repaired (the module has to compile),
only 4 of 59 cases are clean; the agent gets no marked broken lines while all prompt-only runs do (the lines the reference repair changes); relaxed Java agent columns use the plain pass (workspaces deleted; the checked count equalled it before).
