Reading: the higher limit removes almost all call-limit exits and context errors. On Java it lifts the agent by ~16 points (strict 47.4 -> 63.4, relaxed 57.3 -> 70.3; paired +14/-5 and +11/-4) to the level of the best free prompt-only model (particle-1 66.9%; paired relaxed +11/-10). On Python it makes no measurable difference (46.1 -> 48.0, paired +10/-8): the agent stays below particle-1 with the failure output (57-58%). Rule failures (editing more than the method, other files) fall on Java (25 -> 12) but not on Python (12 -> 12). Samples are small (59-61 cases, ~7 points per group) and the runs are sampled at temperature 0.7, so single differences of a few cases are noise.
