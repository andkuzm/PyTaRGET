# Solo strong-arm baseline (Sonnet 5.5 sub-agent, no delegate): what a repair costs, so it need not be re-measured

20 solo runs on 12 tasks (generated rule projects, ledger, shop, gson, five real TaRBench commit pairs). Generated by `scripts/delegation/solo_baseline.py` (rerun it after new solo runs). Tokens are the strong arm's own: output tokens, model calls, added context (growth of the context over the run) and work (extra input tokens processed beyond the fixed ~44k start-up context of the sub-agent, which every call re-reads from cache and is not counted). Size features come from the real repair (reference tests vs old tests). The runs of the repo-set and real phases read their prompt file first (+1 call versus the earlier shop/gson/ledger pilots, whose numbers were copied from docs/results/delegation_strong_arm_work.md and delegation_ledger_work.md).

## How to use it (rules of thumb from these runs)
- **Floor for a scripted fix** (one search-and-replace or one short computation script does everything, however many files): about 0.8-1.3k output tokens, 5-6 model calls, ~6-12k added context, 20-50k work. Examples: rules_rename/logic/big/exc, ta4j (15 files), tablesaw (5 files), gson_a80. Output tokens barely depend on the number of files here (85-210 per file) because the same script touches them all.
- **Hand-written repairs** (each failing test needs its own new code): about 15-60 output tokens per changed test method for light edits, and 90-160 per changed method when the agent writes whole new assertions or helpers (shop 140, ledger 91, LogicNG 161, cactoos 60 plus a helper class). Estimate = changed test methods x that range, never below the floor.
- **Outlier:** LogicNG pair b (39 files, 123 methods, 1234 changed lines, 125k source diff chars, real semantic edits): 58 calls, 19.8k output tokens, 3.9M work: the cost grows with the number of DISTINCT things to understand, not with lines.
- **Predictors:** across the 12 tasks the output tokens correlate with the source diff size (r = 0.95), changed lines (0.90) and changed files (0.85), changed methods (0.72) - but this is driven by the LogicNG outlier and n is small; do not read it as a law. The scripted-vs-hand-written split explains more: tokens per 100 changed lines are 330-1900 for scripted fixes and 1600-3700 for hand-written ones.
- Budget check for planning: a solo run of a typical small/medium fix costs about 1-1.5k output tokens and 45-55k total reported subagent tokens (of which ~44k is the fixed start-up context); about 0.2-0.5 usage points per run in the weekly percentage.

## Caveats
Per-method figures are run totals divided by the number of changed methods (not measured per test). n is 1-2 runs per task; the pilots (shop, gson, ledger) had different prompts (no pointer file, a developer handoff on ledger/shop) and one call fewer. Strict success (no deleted tests, not fewer assertions than the reference) is met by all solo runs except LogicNG b (it deleted 3-4 tests the new API cannot express).
